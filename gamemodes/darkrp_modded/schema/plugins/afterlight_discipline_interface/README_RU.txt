AFTERLIGHT DISCIPLINE INTERFACE v1.6
Готический HUD, круговое меню и шлюз применения способностей дисциплин

ИЗМЕНЕНИЯ v1.6 — ВИРТУАЛЬНЫЕ ДИСЦИПЛИНЫ И КУЛДАУНЫ
=====================================================
- Добавлены interface-only дисциплины, не требующие выдачи или записи в чарлист.
- G-меню и серверный шлюз используют общий контроль доступа для обычных и виртуальных дисциплин.
- Добавлена динамическая серверная стоимость через `GetVitaeCost(context)`.
- Сервер синхронизирует оставшийся откат владельцу. HUD показывает число секунд, radial menu — `ОТКАТ Nс`.
- Mouse3 остаётся единственным способом применения выбранной силы; прокрутка не активирует способность.
- Для этой версии требуется VTM Stats v1.9+.


КРИТИЧЕСКОЕ ИСПРАВЛЕНИЕ ЗАГРУЗКИ HUD v1.5
==========================================
- Повторный скриншот подтвердил, что исправление v1.4 не обеспечило исполнение HUD-модуля на целевой установке.
- `cl_hud.lua` физически перенесён из произвольного корня плагина в `derma/cl_hud.lua`.
- Helix гарантированно выполняет `ix.util.IncludeDir(path .. "/derma", true)` до загрузки `sh_plugin.lua`; это тот же механизм, через который уже успешно загружается работающее круговое меню.
- Ручной include удалён: HUD и wheel теперь находятся в одном гарантированно клиентском autoload-каталоге.
- При загрузке клиент выводит подтверждение `[Afterlight Discipline Interface] client HUD module loaded from derma/cl_hud.lua`.
- Добавлена диагностическая команда `afterlight_discipline_hud_debug`, показывающая регистрацию HUDPaint, статус вампира, ошибку материала и текущие отступы.
- Условие показа не изменилось: любой `character:IsVampire()` получает рамку даже без выданных дисциплин.
- По рабочему скриншоту рамка уменьшена с 112 до 78 базовых пикселей.
- Буква-заглушка `Д` полностью удалена: пустая рамка теперь действительно остаётся пустой.
- Удалены подписи `Дисциплины` и `Способность не выбрана`, а также весь прямоугольный текстовый plaque под пустой рамкой.
- После выбора реальной способности под иконкой остаётся только её название без фоновой панели и без рамки, как требовалось в исходном интерфейсном контракте.

КРИТИЧЕСКОЕ ИСПРАВЛЕНИЕ HUD v1.4
================================
- По скриншоту подтверждено: Vitae HUD загружался, а окно дисциплины отсутствовало полностью.
- Причина найдена в загрузке Helix: каталоги `libs/` и `derma/` подключаются автоматически, но произвольный корневой файл `cl_hud.lua` сам по себе не исполнялся.
- В `sh_plugin.lua` добавлен обязательный `ix.util.Include("cl_hud.lua")`.
- Теперь регистрируется hook `HUDPaint` и нижняя правая рамка действительно создаётся у любого персонажа с `character:IsVampire()`, даже при пустом списке дисциплин.
- Положение по умолчанию остаётся левее узкого индикатора Vitae; выбранная способность показывает иконку своей дисциплины.

ИСПРАВЛЕНИЕ v1.2 — КОРРЕКТНОЕ РАЗМЕЩЕНИЕ MATERIALS
===================================================
- Графические файлы вынесены из каталога Helix-плагина в корневой каталог пакета `materials/afterlight/disciplines`.
- При установке эта папка должна попасть в `garrysmod/materials/afterlight/disciplines`, откуда Source действительно монтирует материалы для `Material(...)`.
- Сервер регистрирует фон, HUD-рамку и все уникальные иконки через `resource.AddFile`, чтобы клиенты получали их без Workshop-пакета при корректно настроенной загрузке контента.
- Четыре пути Тауматургии теперь ссылаются буквально на один файл `thaumaturgy.png`, а не на четыре одинаковые копии.
- Иконка Смертоносности остаётся отдельной копией Некромантии по выбранному решению.

ИЗМЕНЕНИЯ v1.1
===============
- Круговое меню полностью переработано в готическом стиле: затемнение мира, дымчато-кровавый круг, гравированные концентрические кольца, рунические засечки, шипы, подсветка печатей и центральный реликварий.

- Иконка Некромантии также назначена Смертоносности по выбранному решению.

Статус: UI/API-инфраструктура готова; конкретные способности пока не зарегистрированы и не реализованы.

ЗАВИСИМОСТИ
============
- afterlight_vampire_foundation v1.10
- afterlight_vtm_stats v1.9 или новее
- afterlight_vitae рекомендуется для будущих способностей с расходом крови

УПРАВЛЕНИЕ
===========
- Удерживать G: открыть круговое меню дисциплин.
- Навести курсор на внешнее кольцо: выбрать выданную дисциплину.
- Перевести курсор на внутреннее кольцо: выбрать доступную способность.
- Отпустить G: подтвердить наведённую способность.
- Нажать среднюю кнопку мыши: запросить применение выбранной способности.

ДОСТУП
======
Меню и HUD работают только у `character:IsVampire()`. HUD всегда показывается корректному вампиру, даже при пустом списке дисциплин. Круговое меню на G открывается только при наличии хотя бы одной явно выданной дисциплины. Дисциплины нулевого уровня видны во внешнем кольце, но не открывают способности.

СПОСОБНОСТИ
===========
Меню не создаёт фиктивные «Способность I–V». Оно показывает только силы, зарегистрированные будущими discipline-плагинами. Доступны только силы с required level не выше текущего уровня дисциплины.

Пример регистрации:

ix.disciplines.RegisterPower("obfuscate", "cloak_of_shadows", {
    name = "Покров теней",
    description = "Описание силы.",
    level = 1,
    icon = "afterlight/disciplines/obfuscate/cloak.png",
    vitaeCost = 0,
    CanActivate = function(context)
        return true
    end,
    OnActivate = function(context)
        -- Вся механика выполняется сервером.
        return true
    end
})

ПУБЛИЧНЫЙ API
==============
ix.disciplines.RegisterPower(disciplineID, powerID, definition)
ix.disciplines.GetPower(disciplineID, powerID)
ix.disciplines.GetPowers(disciplineID)
ix.disciplines.GetAvailablePowers(character, disciplineID)
ix.disciplines.GetSelectedPower(character)

Сервер:
ix.disciplines.SelectPower(character, disciplineID, powerID)
ix.disciplines.ClearSelectedPower(character)

Hooks:
CanCharacterSelectDisciplinePower(character, power)
OnCharacterSelectedDisciplinePower(character, power)
CanCharacterUseDisciplinePower(character, power, context)
OnCharacterUsedDisciplinePower(character, power, context)

БЕЗОПАСНОСТЬ
============
Клиент отправляет серверу ID только при выборе. При применении средняя кнопка не отправляет ID, уровень, стоимость, цель или результат: сервер читает сохранённый выбор и повторно проверяет вид, выданную дисциплину, уровень и регистрацию силы. Сервер самостоятельно формирует eye trace. Запросы выбора и применения ограничены по частоте.

HUD
===
HUD расположен справа внизу, левее узкого резервуара Vitae. Компактная готическая рамка существует у вампира даже при полностью пустом чарлисте и до выбора остаётся без буквы, подписи и нижней панели. После выбора внутри выводится иконка именно выбранной дисциплины, а ниже — только название реальной способности без фоновой рамки.

Иконки находятся в `materials/afterlight/disciplines/icons/*.png` и имеют настоящий прозрачный alpha-фон. Реестр VTM Stats автоматически дополняется полем `definition.icon`. Для будущей силы `power.icon` остаётся доступен отдельно, но основное окно HUD приоритетно показывает печать дисциплины.

УСТАНОВКА
=========
Из архива необходимо установить ОБЕ корневые папки:

1. `plugins/afterlight_discipline_interface` → `garrysmod/gamemodes/afterlight/schema/plugins/afterlight_discipline_interface`
2. `materials/afterlight/disciplines` → `garrysmod/materials/afterlight/disciplines`

После копирования полностью перезапустить сервер. Если используется FastDL, файлы PNG также должны быть доступны на FastDL; `resource.AddFile` уже добавлен плагином. При распространении через Workshop корневая структура addon должна содержать те же `materials/afterlight/disciplines/*`.
